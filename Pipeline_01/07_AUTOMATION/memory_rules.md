## Salvare sempre
- risultati dei test
- parametri usati
- errori e anomalie
- decisioni prese
- assunzioni ancora aperte
- prossimi passi concreti

## Non salvare
- dati duplicati
- metriche senza contesto
- conclusioni non riproducibili

## Struttura consigliata
- teoria -> concetti e modelli
- strategie -> idee, testati, scartati
- backtest -> protocolli e risultati
- logs -> cronologia esperimenti
- memory -> stato progetto, decisioni, backlog, contesto assistente

## Regola chiave
La memoria deve permettere di riprendere il lavoro senza rileggere tutta la chat.
